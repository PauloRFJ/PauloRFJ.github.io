## Como atualizar
Este repositório recebe a pasta `publicar/` montada no computador:
1. Em `landing-pages/meka-studio`, rode `python gerar-identidade.py --todos` (se mudou alguma identidade) e `python montar-publicacao.py`.
2. Copie o conteúdo de `publicar/` para cá, faça o commit e o push.
3. Em 1 a 2 minutos, o site atualiza sozinho.

## Projetos
Os sites dos clientes ficam nas subpastas (paulorfj.github.io/nome-do-cliente/). Os repositórios de origem de cada cliente são privados.
As páginas de identidade mostram as imagens com marca d'água; os arquivos originais só saem no pacote criptografado de `marca/`, aberto com a senha de cada cliente.

## Domínio próprio
Em **Settings → Pages → Custom domain**, informe mekastudio.com.br. Os projetos passam a abrir em mekastudio.com.br/nome-do-repositorio/ automaticamente.
