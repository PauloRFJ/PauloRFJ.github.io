## Como atualizar
1. Abra este repositório no GitHub.
2. Clique em **Add file → Upload files**.
3. Arraste os arquivos novos (com os mesmos nomes) e clique em **Commit changes**.
4. Em 1 a 2 minutos, o site atualiza sozinho.

## Projetos
Cada projeto de cliente fica em um repositório próprio e aparece em paulorfj.github.io/nome-do-repositorio/.

## Domínio próprio
Em **Settings → Pages → Custom domain**, informe mekastudio.com.br. Os projetos passam a abrir em mekastudio.com.br/nome-do-repositorio/ automaticamente.
